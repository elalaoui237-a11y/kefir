# LYLA Food — متجر حبوب الكفير الحية

موقع المتجر (صفحة واحدة، عربي/دارجة، RTL) مستضاف على GitHub Pages.

## تشغيل محلي
```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## الملفات
```
index.html          كل شي: التصميم + السكريبت (HTML/CSS/JS بلا أي مكتبة خارجية)
images/             الصور (صور أشخاص حقيقيين + صور الكفير)
functions/          (فقط فالمستودع الأساسي) دالة تسجيل الطلبات
```

## الطلبيات
استمارة الطلب كتصيفط الطلبية لهاد الـ endpoint:
```
https://base44.app/api/apps/6ae231e376f8435c23a48922/functions/createKefirOrder
```
وكتتسجل فقاعدة البيانات (جدول `KefirOrder`) بحقول: الاسم، الهاتف، المدينة، العنوان،
العرض، الثمن، ملاحظة، الحالة (`new` / `confirmed` / `shipped` / `delivered` / `cancelled`).

## شنو تبدل قبل ما تنشر
1. **رقم الواتساب** — فآخر `index.html`، فـ `CONFIG`:
   ```js
   const CONFIG = { whatsapp: "2126XXXXXXXX", instagram: "https://instagram.com/..." };
   ```
2. **الأثمنة** — كاينة فجوج بلايص: كروت المنتجات (HTML) وفـ `<input data-price>` داخل الاستمارة،
   وزيادة فدالة `createKefirOrder` (جدول `PACKS`). خاصهم يكونو متطابقين.
3. **الصور** — كل الصور ديال المنتج. باش تبدل صورة، حط الملف الجديد بنفس الاسم فـ `images/`:
   `product-milk-jar.jpg` (قنينة الحبوب), `kefir-grains.jpg` (الحبيبات), `kefir-compare.jpg`
   (الحليب مقابل الماء), `kefir-bottles.jpg` (المشروب), `kefir-montage.jpg`,
   `infographic-water-kefir.jpg` (أنفوغرافيك الفوائد), `food-*.jpg` (مشاهد الحليب).
   الصور ديال الفيديوهات كتجي أوتوماتيكيًا من `videos/*.jpg`.

> ملاحظة: صور الأشخاص اللي كاينة دابا هي صور فوتوغرافية حقيقية من مكتبة Pexels
> (رخصة مجانية للاستعمال التجاري)، ولكن ماشي زبناء حقيقيين ديال المتجر.
> من الأفضل تبديلها بصور ديال زبنائك ملّي تجمعهم.

## الفيديوهات
قسم «شوفو الكفير بعينيك» فيه 3 بلايص جاهزة. غير حط الفيديوهات فالريبو بهاد الأسماء بالضبط:

```
videos/kefir-preparation.mp4   → طريقة التحضير
videos/kefir-straining.mp4     → التصفية والاستهلاك
videos/kefir-grains.mp4        → الحبوب كتتكاثر
```

السكريبت كيشوف واش الملف كاين: إلا كان كيعرض الفيديو بلاصة «قريبًا»، إلا ماكانش كيبقى placeholder.
ملاحظة: GitHub Pages كيحدّد حجم الريبو فـ 1 غيغا، والفيديو الطويل خاصو يكون مضغوط (MP4/H.264، 720p كافي للويب).

## النشر (GitHub Pages)
الموقع كيتنشر أوتوماتيكيًا من الفرع `main`. أي تعديل: بدّل الملف و `git push`،
و GitHub كيعاود يبني الصفحة فـ 30-60 ثانية.


## دومين خاص (Domain)

السيت مستضاف على GitHub Pages وكيبقى خدام بلا ما تدير شي حاجة: كل `push` لـ`main` كيعاود ينشر أوتوماتيكيًا.

منين تكون واجد باش تربط دومين بحال `lylafood.ma`:

1. فـ GitHub: **Settings → Pages → Custom domain** وكتب الدومين.
2. فـ DNS ديال الدومين، زيد هاد السجلات:
   - دومين رئيسي (`lylafood.ma`): `A` → `185.199.108.153` ، `185.199.109.153` ، `185.199.110.153` ، `185.199.111.153`
   - سب-دومين (`www.lylafood.ma`): `CNAME` → `elalaoui237-a11y.github.io`
3. تسنى شهادة HTTPS (كتاخد من دقائق حتى 24 ساعة) وفعّل **Enforce HTTPS**.

ملاحظة: ملف `CNAME` فجذر الريبو كيتكتب وحدو منين تدير الدومين من Settings. ماتمسحوش.
